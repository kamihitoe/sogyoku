### 简介

并查集（Disjoint Set Union, DSU）主要用于维护若干个不相交集合，支持以下两类操作：

- **合并**两个元素所属集合（merge）
- **查询**某个元素所属集合（find）

并查集把每个集合表示成一棵树，对于每个节点 `x` 记录其父节点 `fa[x]` ，特别地，对于根节点 `fa[x] = x` ．



### 实现

#### 合并

##### 朴素实现

```cpp
void merge(ll x, ll y) {
    x = find(x), y = find(y);
    if (x != y) fa[y] = x;
}
```

##### 按大小合并

小树挂在大树上．

```cpp
// sz[x] 初始值为 1
void merge(ll x, ll y) {
    x = find(x), y = find(y);
    if (x == y) return;
    if (sz[x] < sz[y]) swap(x, y);
    fa[y] = x;
    sz[x] += sz[y];
}
```

##### 按秩合并

浅树挂在深树上．

{{< callout type="info" >}}
  不做路径压缩时，秩就是树高；
  做了路径压缩后，秩不再严格等于真实高度，但仍可以作为合并依据．
{{< /callout >}}


```cpp
// rk[x] 初始值为 0
void merge(int x, int y) {
    x = find(x), y = find(y);
    if (x == y) return;
    if (rk[x] < rk[y]) swap(x, y);
    fa[y] = x;
    if (rk[x] == rk[y]) rk[x]++;
}
```



#### 查询

##### 朴素实现

```cpp
ll find(ll x) {
    while (x != fa[x]) x = fa[x];
    return x;
}
```

##### 路径压缩

把沿途经过的每一个节点直接挂到根节点上．

```cpp
ll find(ll x) {
    if (x == fa[x]) return x;
    return fa[x] = find(fa[x]);
}
```

##### 路径减半

把自己连到爷爷节点，然后跳到爷爷节点．

```cpp
ll find(ll x) {
    while (x != fa[x]) {
        x = fa[x] = fa[fa[x]];
    }
    return x;
}
```

路径压缩和路径减半的均摊时间复杂度均为 $O(\alpha(n))$ ，路径压缩不写按秩/大小合并且遇到长链树时有爆栈风险，实际应用时**建议使用路径减半**．



#### 时间复杂度

在使用**路径压缩** + **按秩/大小合并**后，并查集的单次操作复杂度可以视作 $O(\alpha(n))$ ．

其中 $\alpha(n)$ 是反阿克曼函数，增长极其缓慢，在竞赛范围内可视为常数，故并查集在实际应用中可认为是**常数复杂度**．



### 模板

```cpp
struct DSU {
    vector<ll> fa, sz;
    ll sets;  // 连通块个数
    DSU(ll n){
        init(n);
    }
    void init(ll n) {
        fa.resize(n + 1);
        sz.resize(n + 1, 1);
        sets = n;
        iota(fa.begin(), fa.end(), 0);
    }
    ll find(ll x) {
        while (x != fa[x]) {
            x = fa[x] = fa[fa[x]];  // 路径减半
        }
        return x;
    }
    bool merge(ll x, ll y) {
        x = find(x), y = find(y);
        if (x == y) return false;
        if (sz[x] < sz[y]) swap(x, y);  // 按规模合并
        fa[y] = x;
        sz[x] += sz[y];
        sets--;  // 若成功合并则连通块个数减一
        return true;
    }
    bool same(ll x, ll y) {
        return find(x) == find(y);
    }
    ll size(ll x) {
        return sz[find(x)];
    }
};
```
